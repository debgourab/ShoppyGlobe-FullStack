# Required Submission Screenshots

The backend is connected to MongoDB, so the actual database screenshots must be captured after you run the project against your MongoDB instance.

## MongoDB screenshots

Capture:

- `users` collection showing a registered user.
- `products` collection showing seeded products.
- `carts` collection showing a cart linked to a user.

## Thunder Client screenshots

Capture the API responses listed in `../THUNDERCLIENT_TESTING.md`.

### Important

Do not publish:

- MongoDB connection strings
- `.env` files
- JWT secrets
- real user passwords
- private credentials

The project intentionally does not include fake screenshots because screenshots must represent the user's actual MongoDB and Thunder Client environment.
