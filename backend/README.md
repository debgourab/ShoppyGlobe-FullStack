# ShoppyGlobe Backend

Node.js + Express + MongoDB API for the ShoppyGlobe React application.

See the root `README.md` for complete setup and API documentation.

## Quick start

```bash
npm install
copy .env.example .env
npm run seed
npm run dev
```

Linux/macOS:

```bash
npm install
cp .env.example .env
npm run seed
npm run dev
```

API base URL:

```text
http://localhost:5000/api
```
